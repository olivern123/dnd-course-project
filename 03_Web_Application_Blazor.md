# Blog Post 3 - Web Application (Blazor Frontend)
## Overview
At this stage of our DND course project we developed the user-interactive blazor web application that interacts with our restful API (WasteMangement.API) we created last time.
This web aplication serves as the frontend for users to view, add and manage waste data for now.

The primary goal was to create functional, connected and responsive blazor server app that communicates with our backend through HTTP requests.
